O CRL substitui o RAG para contexto de decisão

Agentes de IA normalmente precisam de 20.000–30.000 tokens para reconstruir o contexto histórico de decisões via RAG. A HEILLON resolve isso com o CRL.

①

Qualquer linguagem, qualquer SO

Python, Java, Go, Node.js, C#, PHP — qualquer coisa que faça HTTP. Windows, Linux, macOS, Docker, serverless. A HEILLON fica na nuvem, o cliente não instala nada.

②

1 endpoint, 1 decisão, 1 HDR

Antes de cada ação crítica: POST /lc2s/execute. Recebe LEGITIMATE ou BLOCKED em ~9ms. O HDR é gerado automaticamente. Zero configuração extra.

③

Hardware: zero

O cliente não hospeda nada. Toda a infraestrutura pesada — ledger, LC²S, HAV, HCC — fica na HEILLON. O cliente faz uma chamada HTTP e recebe a prova.

④

HAV — auditoria autônoma

Configure uma auditoria recorrente: a HEILLON executa automaticamente, gera o HDR de auditoria e entrega. Sem agendamento manual, sem equipe dedicada.

exemplo · python
# 1. Instalar (zero servidor)
import requests
 
# 2. Antes de cada ação crítica
r = requests.post(
  "https://api.heillon.com/lc2s/execute",
  json={
    "actor_id": "scoring-ai-v3",
    "actor_type": "AI",
    "intent": "aprovar crédito R$45k",
    "action_type": "CREDIT_DECISION",
    "domain": "FINANCIAL"
  }
)
 
# 3. Recebe a prova em ~9ms
verdict = r.json()["verdict_code"]
hdr_id = r.json()["hdr"]["id"]
 
# → "LEGITIMATE" · "BLOCKED" · "ESCALATED"
# → HDR-LC2S-XXXX · verificável para sempre

Três módulos do Ciclo 2 adicionam camadas de controlo estrutural para sistemas com agentes autónomos. Todos operam via API, sem instalação adicional.

HCP · CONSTITUTIONAL PRIORITY

Hierarquia normativa com veto pré-execução

Define qual norma prevalece quando há conflito de políticas. Bloqueia a acção antes de acontecer se violar a hierarquia constitucional — nunca após.

POST /hcp/evaluate
HRT · REASONING TOKEN

Hash encadeado do raciocínio do agente

Cada passo de raciocínio do agente de IA é hasheado e encadeado ao anterior. Prova que o processo não foi adulterado — verificável por auditores externos.

POST /hrt/chain
HAV-TRAP · SCOPE ENFORCEMENT

Detector de scope-escape em <100ms

Monitoriza em tempo real se um agente está a tentar executar acções fora do escopo autorizado. Bloqueia antes que aconteça. Zero falsos negativos em produção.

POST /hav-trap/check
