Perguntas frequentes

O que é o HPC Sovereign? ▾
O HPC Sovereign instala o kernel LC²S no teu dispositivo e gera um HDR — Heillon Decision Record — para cada decisão da IA. É uma assinatura criptográfica irrefutável que prova o que a IA fez, quando fez e com que intenção declarada.
Posso cancelar a qualquer momento? ▾
Sim. Não há compromisso mínimo. Cancela directamente no portal de subscrição — acesso em qualquer momento a partir do dashboard HPC. O plano Observação continua disponível gratuitamente após o cancelamento.
Os HDRs continuam acessíveis se cancelar? ▾
Sim. Os HDRs já gerados ficam permanentemente no teu dispositivo. São imutáveis por design — o backend não pode apagá-los nem modificá-los. Apenas a geração de novos HDRs é descontinuada com o cancelamento.
O Council suporta equipas remotas? ▾
Sim. Os 5 dispositivos do plano Council podem estar em qualquer localização geográfica. O painel enterprise consolida a actividade de todos os dispositivos num relatório unificado com timestamp soberano.
Precisei de instalar algum software? ▾
Para a monitorização do browser, instala a extensão HEILLON Sentinel (Chrome). Para o kernel LC²S completo com HDR, o agente local está disponível após a subscrição. O registo é feito aqui no browser — sem necessidade de software para começar.
