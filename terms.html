Ao utilizar qualquer produto ou serviço HEILLON — incluindo heillon.com, hpc.heillon.com, hdr.heillon.com, vitrine.heillon.com e a API HEILLON LC²S — o utilizador ou organização aceita integralmente estes Termos de Uso. Se não concordar com qualquer cláusula, interrompa imediatamente o uso dos serviços.

1. Definições

  • "HEILLON": a empresa, seus produtos, APIs e infraestrutura de Legitimidade Computacional.
  • "Utilizador": qualquer pessoa física ou jurídica que acede ou utiliza produtos HEILLON.
  • "LC²S": Legitimidade Constitucional Computacional Soberana — kernel de decisão da HEILLON.
  • "HDR": Heillon Decision Record — registo criptográfico imutável de uma decisão.
  • "Ledger": base de dados imutável onde os HDRs são selados permanentemente.
  • "HPC": Heillon Personal Core — painel de monitorização de atividade de IA no dispositivo.
  • "API Key / Chave Soberana": credencial de autenticação atribuída ao utilizador.

2. Descrição dos Serviços

A HEILLON fornece infraestrutura de legitimidade computacional, incluindo:

  • API LC²S para geração de HDRs com prova criptográfica de decisões
  • Painel HPC para monitorização de atividade de IA com soberania computacional
  • Verificador público de HDRs (sem conta, sem limite)
  • Protocolo HDR v2.0 aberto (RFC-0001, RFC-0002, RFC-0003)
  • HAV — Heillon Audit Vigil — agendador soberano de auditorias

3. Elegibilidade e Conta

  • Os serviços destinam-se a pessoas maiores de 18 anos e organizações legalmente constituídas.
  • O utilizador é responsável pela veracidade das informações fornecidas (e-mail, identificação).
  • A HEILLON reserva-se o direito de revogar acessos que violem estes termos ou apresentem indício de fraude.
  • O código de acesso HPC é pessoal e intransferível. O compartilhamento é proibido.

4. Uso Permitido

O utilizador pode:

  • Integrar a API LC²S em sistemas próprios para geração de HDRs
  • Usar o painel HPC para monitorizar a atividade de IA no próprio dispositivo
  • Verificar HDRs publicamente usando o verificador online ou via API pública
  • Implementar o protocolo HDR v2.0 em sistemas próprios (protocolo aberto)
  • Referenciar os RFCs HEILLON em documentação técnica e publicações

5. Uso Proibido

É expressamente proibido:

  • Engenharia reversa, descompilação ou tentativa de extrair o código-fonte da HEILLON

  • Sobrecarga intencional da infraestrutura (ataques DDoS, scraping abusivo)
  • Registrar dados falsos, enganosos ou de terceiros sem autorização no Ledger
  • Usar a API para fins ilegais ou que violem direitos de terceiros
  • Compartilhar, vender ou licenciar a chave soberana a terceiros
  • Criar sistemas que afirmem falsamente ter certificação HEILLON
  • Registrar dados pessoais de terceiros no Ledger sem base legal adequada

6. Natureza Imutável do Ledger

ATENÇÃO: Dados registrados no Ledger HEILLON são permanentes e irremovíveis por design arquitetural. A integridade da cadeia criptográfica depende desta imutabilidade. O utilizador é exclusivamente responsável por garantir que os dados inseridos nos campos de intenção, contexto e actor_id não contenham dados pessoais de terceiros sem base legal. A HEILLON não pode e não irá apagar registros individuais do Ledger.
