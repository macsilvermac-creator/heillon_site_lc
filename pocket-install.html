Perguntas frequentes
Preciso de criar conta para o Pocket Witness?
Não. O Witness é completamente anónimo. Sem conta, sem email, sem cartão. Instalas e usas imediatamente. Os filtros e o histórico ficam no teu dispositivo.
O Pocket envia os meus dados para algum servidor?
No tier Witness, zero dados saem do teu dispositivo. As análises são feitas localmente. Apenas no upgrade Sovereign o HDR é selado no ledger HEILLON — e mesmo aí, só o que declarares explicitamente.
Funciona com os hubs de AI brasileiros?
Sim — qualquer hub que funcione via browser é monitorizado automaticamente pela extensão. O Pocket não compete com o hub; senta-se por cima de qualquer AI. O token de contexto HDR pode ser colado no início de qualquer conversa em qualquer plataforma.
E as AIs que correm localmente (LM Studio, Ollama)?
Se a AI local corre via browser (localhost), a extensão detecta e monitoriza automaticamente. Para apps nativas usa a PWA com o token de contexto — colas no início da conversa manualmente.
Quando vem a versão paga Sovereign?
Em breve. O botão "SOVEREIGN →" no popup da extensão levará para heillon.com/pocket/upgrade com subscrição mensal e anual via Stripe / Pagar.me.
